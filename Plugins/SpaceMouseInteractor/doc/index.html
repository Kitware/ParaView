SpaceMouse Interactor Plugin

This plugin adds support for 3Dconnexion SpaceMouse to ParaView. On Windows and macOS, it uses the 3Dconnexion driver; on Linux, it uses libspnav and a running spacenavd daemon. The puck controls the camera in the active Render View.

On Linux, 3D mode supports translation and rotation around the view's center of rotation. In 2D mode, lateral motion pans, depth motion zooms, and rotation is limited to the viewing direction. Input is discarded while the server is busy.
